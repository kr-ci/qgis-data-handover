about=Data Handover exports a vector layer to an Excel workbook formatted the way you choose. Decide whether the data becomes an Excel table (filters, sorting, a named table) or a plain range, and set font, size, colour, bold, italic, underline, fill, alignment and wrapping separately for headers and content, plus banded rows, borders (line, colour, all lines / horizontal / outline), title, frozen header, gridlines, column width and print orientation, with a live preview and colour presets. Headers come from aliases, value map codes become labels, numbers keep their unit in the cell format, and identifiers get no thousands separators and are never summed (text identifiers keep their leading zeros). Optional sheets: "Dictionary" (column descriptions) and "About" (source, date, CRS, scope, filter), each with a choice of what goes in, and "Changes" comparing the export with the previous one by a key column. Columns that look like personal data (names, PESEL, e-mail, phone, land register numbers) are left out or masked unless you decide otherwise. Columns calculated from geometry can be added: area or length (on the project ellipsoid), X/Y, latitude/longitude and a "Show on map" link. A totals row (SUBTOTAL, so it follows Excel filters) and a "Summary" sheet with counts, sums, a breakdown by one column and missing data are optional. The same export is a Processing algorithm for batch mode, graphical models and qgis_process, using the settings saved in the window (the title is the layer name; the author's note is not added). Writes XLSX with the openpyxl library: the one in QGIS is used when present, otherwise the copy bundled with the plugin (openpyxl 3.1.5, MIT licence). A "Restore defaults" button resets the look, sheets and file language. Interface and file contents in English, German, French, Spanish, Portuguese, Polish, Russian, Korean, Japanese and Simplified Chinese; the interface language is chosen in the window footer (English by default).
